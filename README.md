# Lourdes — Armá su outfit

Una extensión web del fashion film **"A dónde vamos"** (Grupo 10, IA Generativa y Diseño, UTDT 2026).

Lourdes necesita un outfit: elegí la fiesta, vestila con las prendas y guardá el look.

- Funciona en celular y en computadora, sin instalar nada.
- Las prendas son capas PNG en `img/` (mismo lienzo vertical que `lourdes_base.png`).

Autoras: Ana Marmol, Mora Percaz y Teresa Robles.
